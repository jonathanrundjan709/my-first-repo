## Multi-agent workspace

This repo contains a set of Claude Code subagents (`.claude/agents/`), slash commands (`.claude/commands/`), and orchestration rules (`CLAUDE.md`).
Open it in Claude Code and try `/qa-sweep`, `/investigate <question>`, or `/ship-feature <idea>`.
Add your own agent by dropping a markdown file with `name`, `description`, `tools`, `model` frontmatter into `.claude/agents/`.
